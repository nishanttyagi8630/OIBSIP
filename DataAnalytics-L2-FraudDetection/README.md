# Fraud Detection — OIBSIP Data Analytics (Level 2, Task 3)

## 📌 Objective
Build a machine learning pipeline to detect fraudulent financial transactions from a
heavily imbalanced dataset, addressing class imbalance as a core challenge.

## 🛠 Tech Stack
- Python
- pandas, numpy
- scikit-learn (LogisticRegression, DecisionTreeClassifier)
- imbalanced-learn (SMOTE)
- seaborn, matplotlib
- Jupyter Notebook (Google Colab)

## 📂 Files in this folder
- `Fraud_Detection.ipynb` — full notebook with EDA, class imbalance handling (SMOTE),
  model training, evaluation, and discussion.
- `README.md` — this file.
